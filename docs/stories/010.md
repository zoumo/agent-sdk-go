# US-010 收到重复或未知事件

- 用户目标：收到重复或未知事件。
- 前置条件：各自公开 API 可启动合成原生 peer；使用替换环境和独立超时；不依赖账号或真实 CLI。
- 场景输入：发送两条完全相同但无原生事件 ID 的未知消息，包含大整数与 null。
- 共同验收：保留未知数据，遵守各自去重规则。共同检查位于 `internal/testkit.Check` 的 `US-010` 分支。
- Codex 能力：支持；[原生映射与限制](../../codex/docs/stories/README.md#us-010)。
- Claude 能力：支持；[原生映射与限制](../../claude/docs/stories/README.md#us-010)。
- 自动化：`tests/stories/stories_test.go`，`TestCommonStories/US-010/codex` 和 `/claude`；合成输入为 `tests/stories/peer_test.go`。
- 源码证据：两个适配分别只调用 `codex`、`claude` 的公开 API；[原生测试索引](README.md)。
- 离线证据：上述两个具体子测试执行并通过才计为通过；跳过不计为通过。阶段 B 验证结果见对应阶段提交及 CI。
- 真实运行：未验证；本轮禁止自动运行真实 agent 测试。合成 peer 不证明真实模型、真实 CLI、转发能力或子 agent 成功。
