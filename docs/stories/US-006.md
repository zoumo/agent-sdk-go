# US-006 批准或拒绝权限

- 用户目标：批准或拒绝权限。
- 前置条件：各自公开 API 可启动合成原生 peer；使用替换环境和独立超时；不依赖账号或真实 CLI。
- 场景输入：收到原生权限请求，经原句柄拒绝并再次尝试回答。
- 共同验收：只能沿原始句柄回答。共同检查位于 [`CommonStoriesSuite.checkStory`](../../tests/stories/acceptance_test.go) 的 `US-006` 分支。
- Codex 能力：支持；[原生映射与限制](../../codex/docs/stories/index.md#us-006)。
- Claude 能力：条件支持；[原生映射与限制](../../claude/docs/stories/index.md#us-006)。
- 自动化：`tests/stories/stories_test.go`，`TestCommonStories/TestNativeAdapters/US-006/codex` 和 `/claude`；合成输入为 `tests/stories/peer_test.go`。
- 源码证据：两个适配分别只调用 `codex`、`claude` 的公开 API；[原生测试索引](index.md)。
- 离线证据：上述两个具体子测试执行并通过才计为通过；跳过不计为通过。阶段 B 验证结果见对应阶段提交及 CI。
- 真实运行：未验证；本轮禁止自动运行真实 agent 测试。合成 peer 不证明真实模型、真实 CLI、转发能力或子 agent 成功。
