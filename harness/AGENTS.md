# Harness 文档准则

开始工作前读取 [入口](index.md)，按任务读取对应规范与合同。

## 维护规则

- 设计与规范修改须有人类明确要求或事先同意；授权包含必需的引用同步。
- 开发规范、核心设计合同和共同验收集中在 harness；术语维护在根 [GLOSSARY.md](../GLOSSARY.md)。使用命令、原生来源与证据放在对应 SDK README、来源文件和工具说明。
- 每项规则只维护一处；补充现有文档，不为单次任务创建报告、子索引或模板。历史由 Git 保存。
- harness 只链接本目录及根 GLOSSARY。正文描述确定的目标合同，不保留讨论过程或实现进度，也不把设计目标当成实现或验证结果。
- 采用 OKF v0.2：概念文档包含 type、title、status；根索引声明 okf_version。使用相对链接。
