# Session 单一所有权

## 决定

同一连接上的同一原生主身份只有一个 Session 所有者。原生事件、真实请求及其原句柄、SDK 观察证据由同一 Receive FIFO 交付。交互终止、资源清理与队列排空分别表达。

连接接收与 Session 接收分别定义。不能确认属于某 Session 的原始事件进入有数量、字节及保留期限制的连接级隔离区，报告归属缺口，不交付为该 Session 的成员事件。隔离材料作为诊断读取，不能回答其中请求。后续确认成员时，不将旧材料补插进实时流，也不静默宣称覆盖完整。明确超限或到期的诊断与材料保留范围必须可见。

迁移以共同合同为目标，允许破坏性变更。旧接口只能通过不增加队列、回答权限或资源所有者的薄适配保留；不长期维护旧订阅、回调审批和独立历史流的第二套运行模型。

## 取舍

单一所有权把事件、权限及清理的协调留在 Session 内，代价是调用方必须迁移依赖独立订阅的用法。隔离未知归属避免污染会话，代价是这些早期材料不能承诺在实时流中补回。
