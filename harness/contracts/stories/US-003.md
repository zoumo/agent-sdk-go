# US-003 查看子代理

- 用户目标：查看子代理。
- 场景输入：交付可确认的 child → root 关系以及 child 原生文本。
- 共同验收：保留父子关系和原始来源。

通用目标与边界见[SDK 共同用户故事](../../sdk/user-stories.md)。

## optional-child-detail

用户可在构造时选择保留默认或抑制已确认 child 纯详细交付。两端共同 F1–F5 及原生差异见[子能力验收](child-capabilities.md)；同时覆盖 SDK-US-006/007 的关系、父先结束及 SDK-US-008 发现边界。审批/父结果/关系/完成保留，unknown/mixed 保守保留。
