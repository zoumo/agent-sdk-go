# US-008 回答期间发生取消

- 用户目标：回答期间发生取消。
- 场景输入：覆盖已取消 context 的回答预检查，以及持有原句柄期间 Close 导致句柄失效。共同适配不声称覆盖写入期间所有取消竞态；写入期间与不确定结果分别由 codex/request_contract_test.go 和 claude/permission_cancellation_test.go 等原生测试验证。
- 共同验收：按原生契约报告回答结果。

通用目标与边界见[SDK 共同用户故事](../../sdk/user-stories.md)。
