# US-013 列出当前 Session 的子 Agent

- 用户目标：显式查询当前 Session 关联的子 Agent，不必只靠本次实时事件流发现它们。
- 场景输入：同一 Session 下有本次观察前已经存在的子 Agent、已结束的子 Agent，以及只有部分元数据的子 Agent；另有不属于该 Session 的记录。
- 共同验收：使用原生查询或记录发现能力，返回可确认属于目标 Session 的子 Agent 原生标识与可用元数据，不将无关记录混入结果；不能仅返回本次已观察到的缓存成员。
- 证据边界：没有原生父级或运行状态时保留未知；存在列表记录不表示仍在运行，也不表示已订阅实时事件。查询覆盖或分页不完整必须可识别，不能把部分结果表述为完整列表。
- 操作边界：列表查询本身不触发 resume、历史回放或订阅；自动观察仍遵循 Session 的既有观察合同。列举结果可供调用方后续选择独立操作。

通用目标与边界见[SDK 共同用户故事](../../sdk/user-stories.md)。
