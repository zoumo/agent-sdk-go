# 原生 SDK 通用架构

## 目标与范围

SDK 为应用提供长期 Session 控制和原生事件透传。所有接入方以同一套[共同用户故事](validation-cases.md#stories-sdk-用户故事)验收，不以复制官方 SDK 的全部接口为目标。

共同能力不要求原生协议、参数类型、事件结构或调度结果相同。统一常用控制操作，保留原生表达及证据；不能准确映射的差异须明确暴露。原生限制是能力缺口，不能通过删去共同故事或静默降级掩盖。

## 职责与合同

原生协议负责编解码、未知数据、原生身份和固定版本语义；Session 协调交互、
权限与资源。应用决定输入时机、展示与日志分发、审批策略、超时和任务完成条件。
这些是逻辑职责，不要求另建包或接口继承体系。术语见[术语表](../../GLOSSARY.md)。

| 范围 | 详细合同 |
|---|---|
| 操作、输入、配置与原始请求权限 | [Session 接口](../modules/native-session/design.md#interface-原生-session-公开-interface) |
| 接收顺序、隔离、资源、关闭与排空 | [事件交付](../modules/native-session/design.md#delivery-event-delivery) |
| 成员、可选父级与关系限制 | [关系规则](../modules/native-session/design.md#lineage-shared-relationship-rules) |
| 独立 metadata、主／子保存内容 | [历史查询](../contracts/history-query.md) |

统一常用操作概念，参数保留原生类型；不建立通用 Turn、Busy/Idle 总状态、
跨 Agent 思考档位或预算映射。创建配置与运行中修改分开，requested、accepted、
observed 分开。已知不支持明确拒绝，未知限制保留原生拒绝和不确定性。
不通过排队、抢占、中断、重建 Session 或遍历子 Agent 来模拟原生能力。

## 子 Agent 观察与列举

默认观察覆盖原生证据确认的直接或间接子 Agent，不预设观察层数。
已有转发直接接收；需要额外订阅时自动建立可用观察。自动订阅不启动、恢复或
重跑任务，不批准权限，也不保证补回订阅前遗漏的事件。根执行完成后仍继续观察。
覆盖受限须报告缺口，不能据此认定不可见的 Agent 已停止。

显式列举使用原生查询或保存记录，不以实时缓存代替发现。列表记录不证明运行、
订阅或成员关系；范围、分页及部分结果语义由 Session 接口定义。

## 取消、故障与关闭

原生执行或工具失败作为事件交付，不单独导致 Session 终止。传输、协议等 SDK
故障须报告错误及交互是否终止，不能伪装为正常执行结果。等待取消、中断和资源
关闭的区别及错误结果未知的处理遵循 Session 合同。

## 断线与原生恢复

断线后 SDK 报告错误，由应用决定后续交互；断线不证明执行停止。Codex 的显式
ResumeThread 和 Claude Open 的 ResumeID 保留原生恢复语义，不承诺历史回放。
自动重连、同一对象跨连接续接、补齐缺失事件、恢复旧句柄与应用重启后的持久恢复
均不属于当前合同。

## 设计取舍

- 长期 Session 统一应用目标，保留原生值、调度、执行身份与回答权限。代价是应用须处理协议差异、未知结果和观察缺口，并自行判断任务完成。
- 同连接同主身份只保留一个所有者与一个 Receive FIFO，集中协调事件、权限和清理。应用自行分发消费结果，不维护第二套运行模型。
- 断线由应用处理，历史查询保持独立。这样保留执行可能仍继续的不确定性，不承诺补齐事件、跨连接恢复句柄或应用重启后的持久恢复。
- 默认保留子详细事件，使应用可自行裁剪展示；代价是较大的消费与存储量。可选过滤减少可见细节，但不能替代源输出设置或当作脱敏、费用控制。

### 子 Agent 输出边界

| 层次 | 职责 |
|---|---|
| 原生输出 | Agent 决定连接输出哪些子内容；SDK 显式开启原生选项属于 SDK 配置，不冒充原生默认。 |
| Receive 交付 | SDK 按成员证据交付；父级未知不阻塞已确认成员。过滤只影响此层。 |
| 内部结果回父 | 原生工具结果、状态和完成通知交给父 Agent；不依赖应用消费 Receive 后转交。 |

收到子事件不证明父 Agent 已消费结果，根结果不证明后台全部完成；不保证后台立即唤醒父 Agent，成功、失败与取消也不保证等价结果。无人回答的真实审批可能阻止完成。
Codex 原生 resume 有恢复与附着副作用，不能当作纯订阅；Claude 父 CLI 流的本地分流不等于独立子历史或远端子订阅。

## 新增 Agent

固定官方协议、源码版本、原始文件哈希及许可证，逐项映射共同验收的原生操作和缺口。
明确身份、权限、错误、资源与终止语义后，以公开接口完成离线交互闭环，再覆盖其余能力。
分开记录源码依据、合成测试、实录回放与授权的真实验证；交付前检查独立消费者及分发完整性。
未知或不支持保持显式，不能缩减共同目标、补造原生事实或放宽断言来完成接入。
