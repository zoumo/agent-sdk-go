# SDK 接入规范

本目录规定所有原生 SDK 的共同目标、行为合同与接入流程。设计规范不代表任何接入方已经完成实现或验证。

按以下顺序阅读：

1. [通用架构](architecture.md)：术语、职责、操作与证据边界。
2. [共同用户故事](user-stories.md)：所有 SDK 的共同验收目标。
3. [原生补充用户故事](native-stories.md)：保留共同目标上的原生差异。
4. [接入流程](onboarding.md)：各阶段的输入、产物和完成条件。

共享定义见[术语表](../glossary.md)，设计取舍见[设计决定](../adr/index.md)，详细适配约束见[具体合同](../contracts/index.md)。

共同文档不指定厂商、协议、编程语言、包布局、传输实现或运行时组件；原生补充仅约束差异的表达与验收。具体接入须将原生能力映射到共同合同，并遵守所在项目的工程约束。

- [确定性录制与回放场景](recording-scenarios.md)：固定流程、屏障与证据判定。
